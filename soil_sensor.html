ESP32 Soil Sensor → InfluxDB → Grafana Dashboard

A small plant-monitoring pipeline: an ESP32 reads an RS485 soil probe every five minutes, pushes the readings to InfluxDB Cloud, and a public Grafana dashboard plots them.

Open the live dashboard ↗

Overview

I wanted a no-fuss way to keep an eye on soil moisture and temperature for some houseplants without running a server at home. The whole stack is hosted: the microcontroller talks straight to InfluxDB Cloud over HTTPS, and Grafana Cloud reads from InfluxDB and serves a dashboard I can share with a link. Nothing to maintain beyond the ESP32 itself.

The Grafana dashboard: soil moisture (%) and soil temperature (°C), one point every five minutes. Live version.

Hardware

The probe is a generic sealed RS485 soil moisture and temperature sensor that speaks Modbus RTU at 4800 baud. It exposes two holding registers — moisture and temperature, each scaled by 10 — so a single Modbus read returns both values. The ESP32 talks to it through a MAX13487-based RS485-to-TTL board on UART2 (GPIO 16/17), with GPIO 4 driving the DE/RE pin to switch between transmit and receive around each request, and a bidirectional logic level converter between the 3.3 V ESP32 and the 5 V RS485 board. The ModbusMaster library handles the framing; the two preTransmission/postTransmission callbacks in the sketch just toggle that direction pin.

Logging to InfluxDB

InfluxDB's Arduino client (InfluxDbClient) does most of the work. On boot the ESP32 joins WiFi, syncs its clock over NTP (the InfluxDB Cloud TLS certificate can't be validated without correct time), and checks the connection to the bucket. Each reading is a single Point in the soilSensor measurement with two tags — the device type and the WiFi SSID — and two fields, Soil Moisture and Soil Temperature. The point is serialized to InfluxDB line protocol and written with one HTTPS call, then the loop sleeps for five minutes. That cadence is plenty for soil, and keeps the write volume comfortably inside the free tier.

The bucket name, org ID, and API token live in #defines at the top of the sketch (redacted in the copy below). The token should be a write-only token scoped to the one bucket, so a leaked device can't read anything back.

Pulling the data into Grafana

Grafana Cloud connects to InfluxDB Cloud as a data source using the Flux query language, with the InfluxDB URL, org, and a read token. Each dashboard panel is a short Flux query that selects the measurement and field and lets Grafana pick the aggregation window to match the zoom level:

from(bucket: "PlantLogger")
  |> range(start: v.timeRangeStart, stop: v.timeRangeStop)
  |> filter(fn: (r) => r["_measurement"] == "soilSensor")
  |> filter(fn: (r) => r["_field"] == "Soil Moisture")
  |> aggregateWindow(every: v.windowPeriod, fn: mean, createEmpty: false)

Two time-series panels — one per field — and the dashboard is done. Grafana's public dashboards feature turns it into a read-only page that anyone with the link can view, which is what the button at the top of this page points at.

Automatic watering

With the readings already in hand every cycle, closing the loop is cheap: a small peristaltic pump, switched by a MOSFET from an ESP32 pin, waters the plant whenever the soil is drier than a threshold. Everything a person would want to tune is a #define at the top of the sketch — the pump pin, the moisture threshold, how many seconds to run the pump per dose, the minimum gap between doses (so the water has time to soak down to the probe before the next reading decides it's still dry), and a daily cap on waterings as a safety net if the probe ever fails low. The pump is only allowed to run on a successful Modbus read; a failed read logs a flag and does nothing. Pump seconds and the day's watering count are written to InfluxDB alongside the readings, so each dose shows up on the dashboard next to the moisture curve it caused.

Driving the pump. A logic-level N-channel MOSFET (an IRLZ44N or a small AO3400 both work for a peristaltic pump) as a low-side switch: pump between the pump supply and the drain, source to ground, gate to the ESP32 pin through a ~100 Ω resistor with a 10 kΩ pull-down so the pump stays off while the ESP32 boots. Put a flyback diode across the pump motor (cathode to the supply side), share a common ground between the pump supply and the ESP32, and power the pump from its own supply rather than the ESP32's 3.3 V rail.

Keeping it quiet. Small peristaltic pumps whine at full speed, so the MOSFET gate is driven with 25 kHz PWM from the ESP32's LEDC peripheral rather than switched hard on. PUMP_DUTY_PERCENT sets the speed — around half duty is dramatically quieter, and the dose is made up with a longer PUMP_ON_SECONDS. A 200 ms full-power kick at the start gets the brushed motor turning before it drops to the low duty, and the PWM frequency sits above hearing range so the switching itself adds no tone.

Wireless updates. The sketch also enables ArduinoOTA, so after the first USB flash the board shows up under Tools → Port → Network ports in the Arduino IDE and later uploads go over WiFi. The five-minute wait between readings (and the pump run) is a loop that keeps servicing OTA rather than a blocking delay(), and the OTA start callback drops the pump pin low so an upload can never leave the pump running.

Code

The full ESP32 sketch, including the watering logic. Fill in your own WiFi credentials, InfluxDB org, and token, and set the OTA password, pump pin, threshold, and run time in the block of #defines at the top before flashing.

ESP32 sketch — soil_pump.ino
// ESP32 soil sensor -> InfluxDB Cloud, with automatic watering.
// Reads an RS485 Modbus soil moisture/temperature probe, logs to InfluxDB,
// and runs a peristaltic pump (via a MOSFET) when the soil is drier than a threshold.

#if defined(ESP32)
  #include <WiFiMulti.h>
  WiFiMulti wifiMulti;
  #define DEVICE "ESP32"
#elif defined(ESP8266)
  #include <ESP8266WiFiMulti.h>
  ESP8266WiFiMulti wifiMulti;
  #define DEVICE "ESP8266"
#endif

#include <InfluxDbClient.h>
#include <InfluxDbCloud.h>
#include <ModbusMaster.h>
#include <ArduinoOTA.h>

// ---- WiFi / InfluxDB ----
#define WIFI_SSID "your-wifi-ssid"
#define WIFI_PASSWORD "your-wifi-password"
#define INFLUXDB_URL "https://us-east-1-1.aws.cloud2.influxdata.com"
#define INFLUXDB_TOKEN "your-influxdb-api-token"
#define INFLUXDB_ORG "your-influxdb-org-id"
#define INFLUXDB_BUCKET "PlantLogger"
#define TZ_INFO "UTC-6"

// ---- Over-the-air updates ----
// After the first USB upload, the board appears under Tools > Port > Network ports as OTA_HOSTNAME.
#define OTA_HOSTNAME "soil-sensor"
#define OTA_PASSWORD "change-me"      // the IDE asks for this before a wireless upload

// ---- Watering configuration (edit these) ----
#define PUMP_PIN 26                  // GPIO driving the pump MOSFET gate (low-side N-channel)
#define MOISTURE_THRESHOLD 20.0      // % soil moisture: water when a reading is below this
#define PUMP_ON_SECONDS 10           // how long to run the peristaltic pump per watering
#define PUMP_DUTY_PERCENT 50         // pump speed, 0-100. Lower = quieter, slower; raise PUMP_ON_SECONDS to match
#define PUMP_KICK_MS 200             // brief full-power kick so the motor starts reliably at low duty
#define PUMP_PWM_HZ 25000            // above hearing range, so the PWM itself doesn't whine
#define MIN_WATER_INTERVAL_MIN 60    // minimum time between waterings, so water can soak in
#define MAX_WATERINGS_PER_DAY 6      // safety cap in case the probe reads low or fails
#define READ_INTERVAL_MIN 5          // minutes between sensor readings

// ---- RS485 / Modbus ----
#define RXD2 16
#define TXD2 17
#define RS485_DE_RE 4
HardwareSerial RS485Serial(2);       // UART2
ModbusMaster node;

InfluxDBClient client(INFLUXDB_URL, INFLUXDB_ORG, INFLUXDB_BUCKET, INFLUXDB_TOKEN, InfluxDbCloud2CACert);
Point sensor("soilSensor");

// Watering state
unsigned long lastWaterMillis = 0;
bool hasWatered = false;
int wateringsToday = 0;
unsigned long dayStartMillis = 0;

void preTransmission()  { digitalWrite(RS485_DE_RE, HIGH); }
void postTransmission() { digitalWrite(RS485_DE_RE, LOW); }

// ---- Pump PWM (ESP32 LEDC peripheral) ----
// Works with both the 2.x and 3.x esp32 Arduino cores, whose LEDC APIs differ.
#define PUMP_PWM_BITS 8
#define PUMP_PWM_CHANNEL 0
void pumpSetup() {
#if defined(ESP_ARDUINO_VERSION_MAJOR) && ESP_ARDUINO_VERSION_MAJOR >= 3
  ledcAttach(PUMP_PIN, PUMP_PWM_HZ, PUMP_PWM_BITS);
#else
  ledcSetup(PUMP_PWM_CHANNEL, PUMP_PWM_HZ, PUMP_PWM_BITS);
  ledcAttachPin(PUMP_PIN, PUMP_PWM_CHANNEL);
#endif
}
void pumpSet(int percent) {
  percent = constrain(percent, 0, 100);
  uint32_t duty = (uint32_t)percent * ((1u << PUMP_PWM_BITS) - 1) / 100u;
#if defined(ESP_ARDUINO_VERSION_MAJOR) && ESP_ARDUINO_VERSION_MAJOR >= 3
  ledcWrite(PUMP_PIN, duty);
#else
  ledcWrite(PUMP_PWM_CHANNEL, duty);
#endif
}
void pumpOff() { pumpSet(0); }

void setup() {
  Serial.begin(115200);

  // Pump off before anything else, so it can't run during boot
  pinMode(PUMP_PIN, OUTPUT);
  digitalWrite(PUMP_PIN, LOW);
  pumpSetup();
  pumpOff();

  WiFi.mode(WIFI_STA);
  wifiMulti.addAP(WIFI_SSID, WIFI_PASSWORD);
  Serial.print("Connecting to wifi");
  while (wifiMulti.run() != WL_CONNECTED) {
    Serial.print(".");
    delay(100);
  }
  Serial.println();

  // Accurate time is needed for TLS certificate validation
  timeSync(TZ_INFO, "pool.ntp.org", "time.nis.gov");

  if (client.validateConnection()) {
    Serial.print("Connected to InfluxDB: ");
    Serial.println(client.getServerUrl());
  } else {
    Serial.print("InfluxDB connection failed: ");
    Serial.println(client.getLastErrorMessage());
  }

  sensor.addTag("device", DEVICE);
  sensor.addTag("SSID", WiFi.SSID());

  // OTA: make sure the pump is off if an upload interrupts a watering
  ArduinoOTA.setHostname(OTA_HOSTNAME);
  ArduinoOTA.setPassword(OTA_PASSWORD);
  ArduinoOTA.onStart([]() { pumpOff(); Serial.println("OTA update starting"); });
  ArduinoOTA.onEnd([]()   { Serial.println("
OTA update done, rebooting"); });
  ArduinoOTA.onError([](ota_error_t e) { Serial.printf("OTA error %u
", e); });
  ArduinoOTA.begin();
  Serial.printf("OTA ready: %s at %s
", OTA_HOSTNAME, WiFi.localIP().toString().c_str());

  pinMode(RS485_DE_RE, OUTPUT);
  digitalWrite(RS485_DE_RE, LOW);
  RS485Serial.begin(4800, SERIAL_8N1, RXD2, TXD2);
  node.begin(1, RS485Serial);
  node.preTransmission(preTransmission);
  node.postTransmission(postTransmission);

  dayStartMillis = millis();
}

// Wait for the given number of milliseconds while keeping OTA (and WiFi) serviced.
// A plain delay() would leave the board unreachable for wireless uploads.
void waitAndServiceOTA(unsigned long ms) {
  unsigned long start = millis();
  while (millis() - start < ms) {
    ArduinoOTA.handle();
    delay(10);
  }
}

// Run the pump for PUMP_ON_SECONDS at PUMP_DUTY_PERCENT, then stop.
// A short full-power kick gets the motor turning before dropping to the quieter duty.
void runPump() {
  Serial.printf("Watering: pump on for %d s at %d%%
", PUMP_ON_SECONDS, PUMP_DUTY_PERCENT);
  pumpSet(100);
  waitAndServiceOTA(PUMP_KICK_MS);
  pumpSet(PUMP_DUTY_PERCENT);
  waitAndServiceOTA((unsigned long)PUMP_ON_SECONDS * 1000UL);
  pumpOff();
  lastWaterMillis = millis();
  hasWatered = true;
  wateringsToday++;
}

// Decide whether to water given a valid moisture reading.
// Returns the number of seconds pumped (0 or PUMP_ON_SECONDS).
int maybeWater(float moisture) {
  // Roll the daily counter every 24 h
  if (millis() - dayStartMillis >= 24UL * 60UL * 60UL * 1000UL) {
    dayStartMillis = millis();
    wateringsToday = 0;
  }
  if (moisture >= MOISTURE_THRESHOLD) return 0;

  if (hasWatered && (millis() - lastWaterMillis) < (unsigned long)MIN_WATER_INTERVAL_MIN * 60UL * 1000UL) {
    Serial.println("Soil is dry, but the last watering was too recent - waiting");
    return 0;
  }
  if (wateringsToday >= MAX_WATERINGS_PER_DAY) {
    Serial.println("Soil is dry, but the daily watering cap is reached - not watering");
    return 0;
  }
  runPump();
  return PUMP_ON_SECONDS;
}

void loop() {
  float humidity = 0, temperature = 0;
  bool readOk = false;
  int pumpedSeconds = 0;

  uint8_t result = node.readHoldingRegisters(0x0000, 2);
  if (result == node.ku8MBSuccess) {
    humidity = node.getResponseBuffer(0) / 10.0;
    temperature = node.getResponseBuffer(1) / 10.0;
    readOk = true;
    Serial.printf("Moisture: %.1f %%, Temp: %.1f C
", humidity, temperature);
  } else {
    Serial.printf("Modbus read failed (code %d) - no watering this cycle
", result);
  }

  // Only ever water on a good reading
  if (readOk) {
    pumpedSeconds = maybeWater(humidity);
  }

  // Build the InfluxDB point. Tags stay; fields are cleared each cycle.
  sensor.clearFields();
  if (readOk) {
    sensor.addField("Soil Moisture", humidity);
    sensor.addField("Soil Temperature", temperature);
  }
  sensor.addField("Pump Seconds", pumpedSeconds);
  sensor.addField("Waterings Today", wateringsToday);
  sensor.addField("Read OK", readOk ? 1 : 0);

  Serial.print("Writing: ");
  Serial.println(sensor.toLineProtocol());

  if (wifiMulti.run() != WL_CONNECTED) {
    Serial.println("Wifi connection lost");
  }
  if (!client.writePoint(sensor)) {
    Serial.print("InfluxDB write failed: ");
    Serial.println(client.getLastErrorMessage());
  }

  Serial.printf("Waiting %d minutes (OTA stays available)

", READ_INTERVAL_MIN);
  waitAndServiceOTA((unsigned long)READ_INTERVAL_MIN * 60UL * 1000UL);
}
