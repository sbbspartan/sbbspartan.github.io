ESP32 Soil Sensor → InfluxDB → Grafana Dashboard

A small plant-monitoring pipeline: an ESP32 reads an RS485 soil probe every five minutes, pushes the readings to InfluxDB Cloud, and a public Grafana dashboard plots them.

Open the live dashboard ↗

Overview

I wanted a no-fuss way to keep an eye on soil moisture and temperature for some houseplants without running a server at home. The whole stack is hosted: the microcontroller talks straight to InfluxDB Cloud over HTTPS, and Grafana Cloud reads from InfluxDB and serves a dashboard I can share with a link. Nothing to maintain beyond the ESP32 itself.

The Grafana dashboard: soil moisture (%) and soil temperature (°C), one point every five minutes. Live version.

Hardware

The probe is a generic sealed RS485 soil moisture and temperature sensor that speaks Modbus RTU at 4800 baud. It exposes two holding registers — moisture and temperature, each scaled by 10 — so a single Modbus read returns both values. The ESP32 talks to it through a MAX13487-based RS485-to-TTL board on UART2 (GPIO 16/17), with GPIO 4 driving the DE/RE pin to switch between transmit and receive around each request, and a bidirectional logic level converter between the 3.3 V ESP32 and the 5 V RS485 board. The ModbusMaster library handles the framing; the two preTransmission/postTransmission callbacks in the sketch just toggle that direction pin.

Logging to InfluxDB

InfluxDB's Arduino client (InfluxDbClient) does most of the work. On boot the ESP32 joins WiFi, syncs its clock over NTP (the InfluxDB Cloud TLS certificate can't be validated without correct time), and checks the connection to the bucket. Each reading is a single Point in the soilSensor measurement with two tags — the device type and the WiFi SSID — and two fields, Soil Moisture and Soil Temperature. The point is serialized to InfluxDB line protocol and written with one HTTPS call, then the loop sleeps for five minutes. That cadence is plenty for soil, and keeps the write volume comfortably inside the free tier.

The bucket name, org ID, and API token live in #defines at the top of the sketch (redacted in the copy below). The token should be a write-only token scoped to the one bucket, so a leaked device can't read anything back.

Pulling the data into Grafana

Grafana Cloud connects to InfluxDB Cloud as a data source using the Flux query language, with the InfluxDB URL, org, and a read token. Each dashboard panel is a short Flux query that selects the measurement and field and lets Grafana pick the aggregation window to match the zoom level:

from(bucket: "PlantLogger")
  |> range(start: v.timeRangeStart, stop: v.timeRangeStop)
  |> filter(fn: (r) => r["_measurement"] == "soilSensor")
  |> filter(fn: (r) => r["_field"] == "Soil Moisture")
  |> aggregateWindow(every: v.windowPeriod, fn: mean, createEmpty: false)

Two time-series panels — one per field — and the dashboard is done. Grafana's public dashboards feature turns it into a read-only page that anyone with the link can view, which is what the button at the top of this page points at.

Code

The full ESP32 sketch. Fill in your own WiFi credentials, InfluxDB org, and token before flashing.

ESP32 sketch — influxdb_example.ino
#if defined(ESP32)
#include <WiFiMulti.h>
WiFiMulti wifiMulti;
#define DEVICE "ESP32"
#elif defined(ESP8266)
#include <ESP8266WiFiMulti.h>
ESP8266WiFiMulti wifiMulti;
#define DEVICE "ESP8266"
#endif

#include <InfluxDbClient.h>
#include <InfluxDbCloud.h>
 // #include <SoftwareSerial.h>
#include <ModbusMaster.h>

// WiFi AP SSID
#define WIFI_SSID "your-wifi-ssid"
// WiFi password
#define WIFI_PASSWORD "your-wifi-password"

#define INFLUXDB_URL "https://us-east-1-1.aws.cloud2.influxdata.com"
#define INFLUXDB_TOKEN "your-influxdb-api-token"
#define INFLUXDB_ORG "your-influxdb-org-id"
#define INFLUXDB_BUCKET "PlantLogger"

// Time zone info
#define TZ_INFO "UTC-6"

// Declare InfluxDB client instance with preconfigured InfluxCloud certificate
InfluxDBClient client(INFLUXDB_URL, INFLUXDB_ORG, INFLUXDB_BUCKET, INFLUXDB_TOKEN, InfluxDbCloud2CACert);

// Declare Data point
Point sensor("soilSensor");

 //RS485 config
 #define RXD2 16
 #define TXD2 17
 #define RS485_DE_RE 4
 HardwareSerial RS485Serial(2); //use uart2
 ModbusMaster node;

 void preTransmission() {
digitalWrite(RS485_DE_RE, HIGH);
 }
 void postTransmission(){
digitalWrite(RS485_DE_RE, LOW);
 }


void setup() {
  Serial.begin(115200);

  // Setup wifi
  WiFi.mode(WIFI_STA);
  wifiMulti.addAP(WIFI_SSID, WIFI_PASSWORD);

  Serial.print("Connecting to wifi");
  while (wifiMulti.run() != WL_CONNECTED) {
    Serial.print(".");
    delay(100);
  }
  Serial.println();

  // Accurate time is necessary for certificate validation and writing in batches
  // We use the NTP servers in your area as provided by: https://www.pool.ntp.org/zone/
  // Syncing progress and the time will be printed to Serial.
  timeSync(TZ_INFO, "pool.ntp.org", "time.nis.gov");


  // Check server connection
  if (client.validateConnection()) {
    Serial.print("Connected to InfluxDB: ");
    Serial.println(client.getServerUrl());
  } else {
    Serial.print("InfluxDB connection failed: ");
    Serial.println(client.getLastErrorMessage());
  }

  sensor.addTag("device", DEVICE);
  sensor.addTag("SSID", WiFi.SSID());

  pinMode(RS485_DE_RE, OUTPUT);
  digitalWrite(RS485_DE_RE, LOW);
  RS485Serial.begin(4800, SERIAL_8N1, RXD2, TXD2);
  node.begin(1, RS485Serial);
  node.preTransmission(preTransmission);
  node.postTransmission(postTransmission);
}


 void loop() {
 uint8_t result;
 float humidity, temperature;

 result = node.readHoldingRegisters(0x0000, 2);
 if (result == node.ku8MBSuccess){
  humidity = node.getResponseBuffer(0)/10.0;
  temperature = node.getResponseBuffer(1)/10.0;
 }
 Serial.printf("Moisture: %.1f %%RH, Temp: %.1f C\n", humidity, temperature);
 
  // Clear fields for reusing the point. Tags will remain the same as set above.
  sensor.clearFields();

  // Store measured value into point
  // Report RSSI of currently connected network
  sensor.addField("Soil Moisture", humidity);
  sensor.addField("Soil Temperature", temperature);

  // Print what are we exactly writing
  Serial.print("Writing: ");
  Serial.println(sensor.toLineProtocol());

  // Check WiFi connection and reconnect if needed
  if (wifiMulti.run() != WL_CONNECTED) {
    Serial.println("Wifi connection lost");
  }

  // Write point
  if (!client.writePoint(sensor)) {
    Serial.print("InfluxDB write failed: ");
    Serial.println(client.getLastErrorMessage());
  }

  Serial.println("Waiting 5 minutes");
  Serial.println();
  delay(300000);
  }
